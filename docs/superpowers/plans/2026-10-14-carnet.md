# Carnet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire le plugin Claude Code `carnet`: des registres de projet validés par l'utilisateur (`/carnet:wrapup`) et des rapports PERSO / ENTREPRISE générés depuis ces registres, claude-mem et graphify (`/carnet:report`).

**Architecture:** Un script Python sans dépendance (`bin/carnet.py` + package `bin/carnet_lib/`) fait toute la partie déterministe et répond en JSON: IDs, index, lecture de claude-mem, période, enregistrement des rapports, contrôle de style. Deux skills (`wrapup`, `report`) pilotent la conversation et la rédaction en appelant ce script. Deux gabarits Markdown portent la structure et les règles de style de chaque rapport.

**Tech Stack:** Python 3.9+ (bibliothèque standard: `argparse`, `json`, `sqlite3`, `re`, `unittest`), Markdown, format de plugin Claude Code (`.claude-plugin/plugin.json`, `skills/<nom>/SKILL.md`).

**Spec:** `docs/superpowers/specs/2026-10-14-carnet-design.md`

## Écarts assumés par rapport à la spec

La spec est approuvée. En préparant le plan, j'ai trouvé sept points qu'elle ne tranchait pas ou que les vraies données de claude-mem contredisent. Ils sont intégrés au plan et reportés dans la spec à la tâche 12.

1. **Date de résolution d'un blocage.** La spec parle des blocages "résolus dans la période" sans dire d'où vient la date. `set-status ... résolu` écrit donc une ligne `- **Résolu le:** AAAA-MM-JJ` dans le blocage.
2. **Mots-clés de période.** `context --since journal` (depuis la dernière entrée du journal) et `context --since rapport --gabarit <g>` (depuis le dernier rapport de ce gabarit) évitent aux skills un premier appel juste pour lire une date. `context` accepte aussi `--gabarit`, nécessaire pour remplir `previous_report`.
3. **Sortie de `context` enrichie.** `project.initialized` (booléen) et `registers.last_dates` (date de la dernière entrée par registre, nécessaire à l'alerte "rien reçu depuis deux semaines" du rituel).
4. **Correspondance claude-mem.** La base réelle contient des sessions enregistrées sous Windows (`cwd` = `C:/Users/...`) ou sans `cwd` (`NULL`). Avec la règle "cwd d'abord, repli sur le nom", ces sessions disparaîtraient dès qu'une seule session Linux correspond par `cwd`. La règle devient: `cwd` égal à la racine ou sous-dossier, plus les sessions de même nom de projet dont le `cwd` est absent ou n'est pas un chemin POSIX. Repli sur le seul nom de projet si rien ne correspond. `match` vaut `"cwd"`, `"name"` ou `"cwd+name"`.
5. **Taille des résumés.** Chaque champ de résumé claude-mem est tronqué à 500 caractères. Le projet RemoteHub a déjà 57 résumés, et `--tout` les renverrait tous.
6. **Date d'un résumé.** C'est la partie date de `created_at` (format réel `2026-10-14T14:59:21.656Z`, donc UTC), pas une conversion de fuseau.
7. **Package.** Le script se découpe en `bin/carnet.py` (point d'entrée) et `bin/carnet_lib/` (un module par responsabilité) plutôt qu'un fichier unique de plus de 600 lignes.

Les résumés réels de claude-mem sont écrits en anglais. Les skills et les gabarits disent de les réécrire en français.

## Global Constraints

- Python 3.9+, bibliothèque standard seulement. Aucune installation par pip.
- Markdown seulement pour les rapports (pas de PDF, Word, HTML).
- Aucun hook. Deux commandes seulement: `/carnet:wrapup` et `/carnet:report`.
- Registres dans `<projet>/.claude/memory/`: `decisions.md`, `learnings.md`, `blockers.md`, `journal.md`, et `reports/`.
- Préfixes d'ID: `BDR` (décisions), `LRN` (apprentissages), `BLK` (blocages). Format `BDR-001`.
- Statuts: décisions `actée` / `remplacée` / `abandonnée`; blocages `ouvert` / `résolu`.
- Rapports enregistrés sous `reports/AAAA-MM-JJ-<gabarit>.md`, suffixe `-2`, `-3` en cas de collision. Gabarits: `perso` et `entreprise`.
- Toutes les commandes du script répondent en JSON sur la sortie standard. Une erreur donne `{"error": "...", "detail": "..."}` et un code de sortie non nul.
- Les écritures passent par un fichier temporaire puis un renommage. Un registre illisible n'est jamais réécrit.
- claude-mem est ouvert en lecture seule (`mode=ro`). Chemin remplaçable par `CARNET_CLAUDE_MEM_DB`.
- Dates au format ISO `AAAA-MM-JJ`. `--since` et `--until` sont inclusifs, au jour près.
- Le ton des rapports est naturel et direct. Le contrôle de style avertit sans jamais bloquer.
- Tests: `python3 -m unittest discover -s tests`. Un seul fichier: `python3 -m unittest discover -s tests -p "test_<nom>.py"`.
- Chaque commit se termine par: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Toutes les commandes du plan se lancent depuis `~/Documents/carnet`.

## Review Focus

Entrées que la spec laisse implicites et qui risquent de casser pour une vraie personne. Chaque ligne est épinglée par un test dans la tâche indiquée.

1. **Titre avec `|` ou valeur sur plusieurs lignes.** Un `|` casserait le tableau d'index, un retour à la ligne casserait la liste de champs. Attendu: le `|` devient `/` dans l'index, les retours à la ligne deviennent des espaces. Tâche 2.
2. **Registre édité dans Obsidian avec fins de ligne Windows (CRLF).** Attendu: lecture correcte, et un `add` qui réussit. Tâche 4.
3. **Chemin de projet ou de base avec espaces, `#` ou accents.** Attendu: la base claude-mem s'ouvre quand même. Tâche 7.
4. **Deux rituels le même jour, et un blocage modifié en fin de fichier.** Attendu: deux entrées de journal, `Suite:` lue sur la dernière, et `set-status` qui insère ses lignes avant les blancs de fin. Tâches 3 et 4.
5. **Projet sans mémoire, sans résumé claude-mem, ou registres vides.** Attendu: un JSON valide avec des listes vides, jamais un plantage. Tâche 8.

```python
import json
import os
import subprocess
import sys
import tempfile
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
BIN = ROOT / "bin"
CLI = BIN / "carnet.py"
sys.path.insert(0, str(BIN))


class ProjectCase(unittest.TestCase):
    """Fournit un dossier projet temporaire, supprimé après chaque test."""

    def setUp(self):
        self._tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self._tmp.cleanup)
        self.root = Path(self._tmp.name).resolve()
        self.memory = self.root / ".claude" / "memory"


def run_cli(*args, root=None, stdin=None, env_extra=None):
    """Lance bin/carnet.py. Renvoie (code de sortie, JSON décodé ou None, stderr)."""
    env = dict(os.environ)
    env["CARNET_TODAY"] = "2026-10-14"
    env["CARNET_CLAUDE_MEM_DB"] = str(ROOT / "tests" / "absent.db")
    if env_extra:
        env.update(env_extra)
    cmd = [sys.executable, str(CLI), *args]
    if root is not None:
        cmd += ["--project-root", str(root)]
    proc = subprocess.run(
        cmd, input=stdin, capture_output=True, text=True, encoding="utf-8", env=env
    )
    out = json.loads(proc.stdout) if proc.stdout.strip() else None
    return proc.returncode, out, proc.stderr
```

```python
from datetime import date
from pathlib import Path

from .errors import CarnetError

MEMORY_REL = Path(".claude") / "memory"
JOURNAL = "journal"

REGISTERS = {
    "decisions": {
        "prefix": "BDR",
        "title": "Décisions",
        "fields": [
            ("decision", "Décision"),
            ("pourquoi", "Pourquoi"),
            ("alternatives", "Alternatives"),
            ("statut", "Statut"),

        "statuses": ["actée", "remplacée", "abandonnée"],
        "required": ["titre", "decision", "pourquoi"],
        "defaults": {"alternatives": "", "statut": "actée"},
    },
    "learnings": {
        "prefix": "LRN",
        "title": "Apprentissages",
        "fields": [
            ("pattern", "Pattern observé"),
            ("contexte", "Contexte"),
            ("application", "Application future"),
        ],
        "index": [("id", "ID"), ("date", "Date"), ("titre", "Titre")],
        "statuses": [],
        "required": ["titre", "pattern", "contexte", "application"],
        "defaults": {},
    },
    "blockers": {
        "prefix": "BLK",
        "title": "Blocages",
        "fields": [
            ("friction", "Friction"),
            ("cause", "Cause réelle"),
            ("solution", "Solution"),
            ("statut", "Statut"),
        ],
        "index": [("id", "ID"), ("date", "Date"), ("titre", "Titre"), ("statut", "Statut")],
        "statuses": ["ouvert", "résolu"],
        "required": ["titre", "friction", "cause"],
        "defaults": {"solution": "", "statut": "ouvert"},
    },
}
ALL_REGISTERS = ["decisions", "learnings", "blockers", JOURNAL]


def today_iso():
    return os.environ.get("CARNET_TODAY") or date.today().isoformat()


def memory_dir(root):
    return Path(root) / MEMORY_REL


def clean(value):
    """Une valeur tient sur une ligne: les retours à la ligne deviennent des espaces."""
    return " ".join(("" if value is None else str(value)).split())


def atomic_write(path, text):
    tmp = path.with_name(path.name + ".tmp")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, path)


def initial_text(name):
    if name == JOURNAL:
        return "---\nregistre: journal\n---\n# Journal\n"
    spec = REGISTERS[name]
    labels = [label for _, label in spec["index"]]
    head = "| " + " | ".join(labels) + " |"
    sep = "|" + "|".join("-" * (len(label) + 2) for label in labels) + "|"
    return (
        f"---\nregistre: {name}\nprefixe: {spec['prefix']}\n---\n"
        f"# {spec['title']}\n\n## Index\n{head}\n{sep}\n"
    )


def init(root):
    mem = memory_dir(root)
    mem.mkdir(parents=True, exist_ok=True)
    (mem / "reports").mkdir(exist_ok=True)
    created, existing = [], []
    for name in ALL_REGISTERS:
        path = mem / f"{name}.md"
        if path.exists():
            existing.append(path.name)
        else:
            atomic_write(path, initial_text(name))
            created.append(path.name)
    return {"memory_dir": str(mem), "created": created, "existing": existing}
```

`bin/carnet.py`:

```python
#!/usr/bin/env python3
"""Carnet: registres de projet et matière première pour les rapports."""
import argparse
import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from carnet_lib import registers  # noqa: E402
from carnet_lib.errors import CarnetError  # noqa: E402

PLUGIN_ROOT = Path(__file__).resolve().parent.parent


def build_parser():
    common = argparse.ArgumentParser(add_help=False)
    common.add_argument(
        "--project-root", default=".", help="dossier racine du projet (défaut: dossier courant)"
    )
    parser = argparse.ArgumentParser(prog="carnet.py", description=__doc__)
    sub = parser.add_subparsers(dest="command", required=True)

    sub.add_parser("init", parents=[common], help="crée .claude/memory/ et les registres")
    return parser


def cmd_init(args, root):
    return registers.init(root)


HANDLERS = {"init": cmd_init}


def emit(payload, code=0):
    sys.stdout.write(json.dumps(payload, ensure_ascii=False, indent=2) + "\n")
    return code


def main(argv=None):
    sys.stdout.reconfigure(encoding="utf-8")
    sys.stdin.reconfigure(encoding="utf-8")
    args = build_parser().parse_args(argv)
    root = Path(args.project_root).resolve()
    try:
        return emit(HANDLERS[args.command](args, root))
    except CarnetError as exc:
        return emit({"error": exc.error, "detail": exc.detail}, 1)


if __name__ == "__main__":
    sys.exit(main())
```

```python
DATE_RE = re.compile(r"^\d{4}-\d{2}-\d{2}$")
REF_RE = re.compile(r"\[\[([A-Z]{3}-\d+)\]\]")


def _bad(path, number, message):
    return CarnetError("registre_illisible", f"{path.name}:{number}: {message}")


def _lines(text):
    return [line.rstrip("\r") for line in text.split("\n")]


def _read(root, name):
    path = memory_dir(root) / f"{name}.md"
    if not path.exists():
        raise CarnetError("registre_absent", f"{path} n'existe pas, lancer `carnet.py init`")
    return path, _lines(path.read_text(encoding="utf-8"))


def _save(path, lines):
    while lines and lines[-1] == "":
        lines.pop()
    atomic_write(path, "\n".join(lines) + "\n")


def _with_block(lines, block):
    out = list(lines)
    while out and out[-1] == "":
        out.pop()
    return out + [""] + block


def _check_header(name, lines, path):
    if not lines or lines[0] != "---":
        raise _bad(path, 1, "header YAML absent")
    try:
        end = lines.index("---", 1)
    except ValueError:
        raise _bad(path, 1, "header YAML non fermé")
    meta = {}
    for line in lines[1:end]:
        key, _, value = line.partition(":")
        meta[key.strip()] = value.strip()
    if meta.get("registre") != name:
        raise _bad(path, 2, f"« registre: {name} » attendu dans le header")
    if name != JOURNAL and meta.get("prefixe") != REGISTERS[name]["prefix"]:
        raise _bad(path, 3, f"« prefixe: {REGISTERS[name]['prefix']} » attendu dans le header")


def _cells(line):
    return [cell.strip() for cell in line.strip().strip("|").split("|")]


def _locate_index(name, lines, path):
    labels = [label for _, label in REGISTERS[name]["index"]]
    try:
        start = lines.index("## Index")
    except ValueError:
        raise _bad(path, 1, "section « ## Index » absente")
    expected = "| " + " | ".join(labels) + " |"
    if start + 2 >= len(lines) or lines[start + 1].strip() != expected:
        raise _bad(path, start + 2, f"en-tête du tableau attendu: {expected}")
    if not re.match(r"^\|[-| :]+\|$", lines[start + 2].strip()):
        raise _bad(path, start + 3, "ligne de séparation du tableau attendue")
    first = start + 3
    end = first
    while end < len(lines) and lines[end].startswith("|"):
        if len(_cells(lines[end])) != len(labels):
            raise _bad(path, end + 1, f"{len(labels)} colonnes attendues")
        end += 1
    return first, end


def _next_id(spec, lines, first, end):
    numbers = [0]
    heading = re.compile(rf"^## {spec['prefix']}-(\d+) · ")
    for line in lines:
        match = heading.match(line)
        if match:
            numbers.append(int(match.group(1)))
    for line in lines[first:end]:
        match = re.fullmatch(rf"{spec['prefix']}-(\d+)", _cells(line)[0])
        if match:
            numbers.append(int(match.group(1)))
    return f"{spec['prefix']}-{max(numbers) + 1:03d}"


def _day(data, today):
    day = clean(data.get("date") or today or today_iso())
    if not DATE_RE.match(day):
        raise CarnetError("date_invalide", day)
    return day


def known_ids(root):
    ids = set()
    for name, spec in REGISTERS.items():
        path = memory_dir(root) / f"{name}.md"
        if path.exists():
            text = path.read_text(encoding="utf-8")
            ids.update(re.findall(rf"^## ({spec['prefix']}-\d+) · ", text, re.M))
    return ids


def _reference_warnings(root, texts, own_id=None):
    known = known_ids(root)
    if own_id:
        known.add(own_id)
    cited = set()
    for text in texts:
        cited.update(REF_RE.findall(text))
    return [f"Référence [[{ref}]] introuvable" for ref in sorted(cited - known)]


def _normalize(spec, data, today):
    missing = [key for key in spec["required"] if not clean(data.get(key, ""))]
    if missing:
        raise CarnetError("champs_manquants", ", ".join(missing))
    entry = {"date": _day(data, today), "titre": clean(data["titre"])}
    for key, _ in spec["fields"]:
        entry[key] = clean(data.get(key) or spec["defaults"].get(key, ""))
    if spec["statuses"] and entry["statut"] not in spec["statuses"]:
        raise CarnetError(
            "statut_invalide",
            f"{entry['statut']} (valeurs possibles: {', '.join(spec['statuses'])})",
        )
    return entry


def _add_journal(root, data, today):
    raw = data.get("lignes") or []
    if isinstance(raw, str):
        raw = [raw]
    lignes = [clean(line) for line in raw if clean(line)]
    suite = clean(data.get("suite", ""))
    missing = [key for key, value in (("lignes", lignes), ("suite", suite)) if not value]
    if missing:
        raise CarnetError("champs_manquants", ", ".join(missing))
    day = _day(data, today)
    path, lines = _read(root, JOURNAL)
    _check_header(JOURNAL, lines, path)
    warnings = _reference_warnings(root, lignes + [suite])
    _save(path, _with_block(lines, [f"## {day}", *lignes, f"Suite: {suite}"]))
    return {"id": None, "date": day, "file": str(path), "warnings": warnings}


def add(root, name, data, today=None):
    if name not in ALL_REGISTERS:
        raise CarnetError("registre_inconnu", name)
    if not isinstance(data, dict):
        raise CarnetError("entree_invalide", "un objet JSON est attendu")
    if name == JOURNAL:
        return _add_journal(root, data, today)
    spec = REGISTERS[name]
    entry = _normalize(spec, data, today)
    path, lines = _read(root, name)
    _check_header(name, lines, path)
    first, end = _locate_index(name, lines, path)
    entry_id = _next_id(spec, lines, first, end)
    warnings = _reference_warnings(root, list(entry.values()), own_id=entry_id)
    cells = [
        entry_id if key == "id" else entry[key].replace("|", "/") for key, _ in spec["index"]
    ]
    lines.insert(end, "| " + " | ".join(cells) + " |")
    block = [f"## {entry_id} · {entry['titre']}", f"- **Date:** {entry['date']}"]
    block += [f"- **{label}:** {entry[key]}".rstrip() for key, label in spec["fields"]]
    _save(path, _with_block(lines, block))
    return {"id": entry_id, "file": str(path), "warnings": warnings}
```

```python
def _register_for_id(entry_id):
    match = re.fullmatch(r"([A-Z]{3})-\d+", entry_id)
    if match:
        for name, spec in REGISTERS.items():
            if spec["prefix"] == match.group(1):
                return name
    raise CarnetError("id_inconnu", entry_id)


def _block_end(lines, heading_index):
    for i in range(heading_index + 1, len(lines)):
        if lines[i].startswith("## "):
            return i
    return len(lines)


def _upsert_line(lines, heading_index, label, value, after_label):
    prefix = f"- **{label}:**"
    text = f"{prefix} {value}".rstrip()
    end = _block_end(lines, heading_index)
    for i in range(heading_index + 1, end):
        if lines[i].startswith(prefix):
            lines[i] = text
            return
    anchor = f"- **{after_label}:**"
    for i in range(heading_index + 1, end):
        if lines[i].startswith(anchor):
            lines.insert(i + 1, text)
            return
    while end > heading_index + 1 and lines[end - 1] == "":
        end -= 1
    lines.insert(end, text)


def _remove_line(lines, heading_index, label):
    prefix = f"- **{label}:**"
    for i in range(heading_index + 1, _block_end(lines, heading_index)):
        if lines[i].startswith(prefix):
            del lines[i]
            return


def set_status(root, entry_id, status, solution=None, today=None):
    name = _register_for_id(entry_id)
    spec = REGISTERS[name]
    if not spec["statuses"]:
        raise CarnetError("statut_non_gere", f"le registre {name} n'a pas de statut")
    if status not in spec["statuses"]:
        raise CarnetError(
            "statut_invalide", f"{status} (valeurs possibles: {', '.join(spec['statuses'])})"
        )
    if solution is not None and name != "blockers":
        raise CarnetError("option_invalide", "--solution ne concerne que les blocages")
    path, lines = _read(root, name)
    _check_header(name, lines, path)
    first, end = _locate_index(name, lines, path)
    row = next((i for i in range(first, end) if _cells(lines[i])[0] == entry_id), None)
    heading = next(
        (i for i, line in enumerate(lines) if line.startswith(f"## {entry_id} · ")), None
    )
    if row is None or heading is None:
        raise CarnetError("id_introuvable", f"{entry_id} dans {path.name}")
    block_end = _block_end(lines, heading)
    if not any(lines[i].startswith("- **Statut:**") for i in range(heading + 1, block_end)):
        raise _bad(path, heading + 1, f"ligne « Statut » absente pour {entry_id}")
    cells = _cells(lines[row])
    cells[[key for key, _ in spec["index"]].index("statut")] = status
    lines[row] = "| " + " | ".join(cells) + " |"
    _upsert_line(lines, heading, "Statut", status, "Date")
    if solution is not None:
        _upsert_line(lines, heading, "Solution", clean(solution), "Cause réelle")
    if name == "blockers":
        if status == "résolu":
            _upsert_line(lines, heading, "Résolu le", today or today_iso(), "Statut")
        else:
            _remove_line(lines, heading, "Résolu le")
    _save(path, lines)
    return {"id": entry_id, "statut": status, "file": str(path)}
```

```python
JOURNAL_HEADING_RE = re.compile(r"^## (\d{4}-\d{2}-\d{2})\s*$")


def read_entries(root, name):
    spec = REGISTERS[name]
    path = memory_dir(root) / f"{name}.md"
    if not path.exists():
        return []
    labels = {label: key for key, label in spec["fields"]}
    labels["Date"] = "date"
    labels["Résolu le"] = "resolu_le"
    heading = re.compile(rf"^## ({spec['prefix']}-\d+) · (.*)$")
    entries, current = [], None
    for line in _lines(path.read_text(encoding="utf-8")):
        match = heading.match(line)
        if match:
            current = {"id": match.group(1), "titre": match.group(2).strip(), "date": ""}
            current.update({key: "" for key, _ in spec["fields"]})
            entries.append(current)
        elif line.startswith("## "):
            current = None
        elif current is not None:
            label = LABEL_RE.match(line)
            if label and label.group(1) in labels:
                current[labels[label.group(1)]] = label.group(2).strip()
    return entries


def read_journal(root):
    path = memory_dir(root) / f"{JOURNAL}.md"
    if not path.exists():
        return []
    entries, current = [], None
    for line in _lines(path.read_text(encoding="utf-8")):
        match = JOURNAL_HEADING_RE.match(line)
        if match:
            current = {"date": match.group(1), "lignes": [], "suite": ""}
            entries.append(current)
        elif line.startswith("## "):
            current = None
        elif current is not None and line.strip():
            if line.startswith("Suite:"):
                current["suite"] = line[len("Suite:"):].strip()
            else:
                current["lignes"].append(line.strip())
    return entries


def last_dates(root):
    result = {}
    for name in REGISTERS:
        dates = [entry["date"] for entry in read_entries(root, name) if entry["date"]]
        result[name] = max(dates) if dates else None
    journal_dates = [entry["date"] for entry in read_journal(root)]
    result[JOURNAL] = max(journal_dates) if journal_dates else None
    return result
```

```python
import re
from pathlib import Path

ID_RE = re.compile(r"\b(?:BDR|LRN|BLK)-\d+\b")
MAX_WORDS_ENTREPRISE = 300


def load_phrases(path):
    path = Path(path)
    if not path.exists():
        return []
    phrases = []
    for raw in path.read_text(encoding="utf-8").splitlines():
        raw = raw.strip()
        if raw and not raw.startswith("#"):
            phrases.append(raw)
    return phrases


def _normalize(text):
    return text.replace("\u2019", "'")


def _warning(number, motif, line):
    return {"line": number, "motif": motif, "extrait": line.strip()[:120]}


def check(text, gabarit, phrases):
    patterns = [
        (phrase, re.compile(r"(?<!\w)" + re.escape(_normalize(phrase)) + r"(?!\w)", re.IGNORECASE))
        for phrase in phrases
    ]
    warnings = []
    for number, line in enumerate(text.split("\n"), start=1):
        if "\u2014" in line:
            warnings.append(_warning(number, "tiret cadratin", line))
        normalized = _normalize(line)
        for phrase, pattern in patterns:
            if pattern.search(normalized):
                warnings.append(_warning(number, f"expression à éviter: {phrase}", line))
        if gabarit == "entreprise":
            for match in ID_RE.finditer(line):
                warnings.append(_warning(number, f"ID interne: {match.group(0)}", line))
            if "[[" in line:
                warnings.append(_warning(number, "référence [[ ]] interne", line))
    if gabarit == "entreprise":
        words = len(text.split())
        if words > MAX_WORDS_ENTREPRISE:
            warnings.append(
                {"line": 0, "motif": f"plus de {MAX_WORDS_ENTREPRISE} mots ({words})", "extrait": ""}
            )
    return warnings
```

```python
import re

from . import registers, style
from .errors import CarnetError

GABARITS = ("perso", "entreprise")
NAME_RE = re.compile(r"^(\d{4}-\d{2}-\d{2})-(perso|entreprise)(?:-(\d+))?\.md$")
DATE_RE = re.compile(r"^\d{4}-\d{2}-\d{2}$")


def reports_dir(root):
    return registers.memory_dir(root) / "reports"


def _check_gabarit(gabarit):
    if gabarit not in GABARITS:
        raise CarnetError("gabarit_inconnu", f"{gabarit} (valeurs possibles: {', '.join(GABARITS)})")


def last_report(root, gabarit):
    _check_gabarit(gabarit)
    folder = reports_dir(root)
    found = []
    if folder.is_dir():
        for path in folder.iterdir():
            match = NAME_RE.match(path.name)
            if match and match.group(2) == gabarit:
                found.append((match.group(1), int(match.group(3) or 1), path))
    if not found:
        return None
    day, _, path = max(found)
    return {"gabarit": gabarit, "date": day, "path": str(path)}


def save_report(root, gabarit, body, du, au, phrases, today=None):
    _check_gabarit(gabarit)
    if not (DATE_RE.match(du) or du == "début"):
        raise CarnetError("date_invalide", f"--du: {du}")
    if not DATE_RE.match(au):
        raise CarnetError("date_invalide", f"--au: {au}")
    day = today or registers.today_iso()
    folder = reports_dir(root)
    folder.mkdir(parents=True, exist_ok=True)
    number = 1
    while True:
        suffix = "" if number == 1 else f"-{number}"
        path = folder / f"{day}-{gabarit}{suffix}.md"
        if not path.exists():
            break
        number += 1
    text = f"---\ngabarit: {gabarit}\ndu: {du}\nau: {au}\n---\n{body.strip()}\n"
    registers.atomic_write(path, text)
    return {"path": str(path), "warnings": style.check(body, gabarit, phrases)}
```

```python
def make_claude_mem_db(path, sessions, summaries):
    """Fausse base claude-mem, avec les colonnes réelles lues par le plugin (claude-mem 13.37.0).

    sessions:  [(memory_session_id, project, cwd)]
    summaries: [(memory_session_id, project, created_at, request, completed, next_steps, files_edited)]
    """
    conn = sqlite3.connect(str(path))
    conn.executescript(
        """
        CREATE TABLE sdk_sessions (
            id INTEGER PRIMARY KEY AUTOINCREMENT, memory_session_id TEXT UNIQUE,
            project TEXT NOT NULL, cwd TEXT);
        CREATE TABLE session_summaries (
            id INTEGER PRIMARY KEY AUTOINCREMENT, memory_session_id TEXT NOT NULL,
            project TEXT NOT NULL, request TEXT, investigated TEXT, learned TEXT,
            completed TEXT, next_steps TEXT, files_read TEXT, files_edited TEXT,
            created_at TEXT NOT NULL, created_at_epoch INTEGER NOT NULL);
        """
    )
    conn.executemany(
        "INSERT INTO sdk_sessions (memory_session_id, project, cwd) VALUES (?, ?, ?)", sessions
    )
    for i, (sid, project, created_at, request, completed, next_steps, files) in enumerate(summaries):
        conn.execute(
            "INSERT INTO session_summaries (memory_session_id, project, request, investigated, "
            "learned, completed, next_steps, files_edited, created_at, created_at_epoch) "
            "VALUES (?, ?, ?, '', '', ?, ?, ?, ?, ?)",
            (sid, project, request, completed, next_steps, files, created_at, i),
        )
    conn.commit()
    conn.close()
```

```python
import json
import os
import re
import sqlite3
from pathlib import Path
from urllib.parse import quote

DEFAULT_DB = Path.home() / ".claude-mem" / "claude-mem.db"
MAX_FIELD_CHARS = 500
MAX_GRAPHIFY_CHARS = 3000
DAY_RE = re.compile(r"^\d{4}-\d{2}-\d{2}")

QUERY = """
SELECT s.created_at, s.request, s.investigated, s.learned, s.completed,
       s.next_steps, s.files_edited, s.project AS project, d.cwd AS cwd
FROM session_summaries s
JOIN sdk_sessions d ON d.memory_session_id = s.memory_session_id
WHERE d.cwd = :root OR substr(d.cwd, 1, :n) = :prefix OR s.project = :name
"""


def db_path():
    return Path(os.environ.get("CARNET_CLAUDE_MEM_DB") or DEFAULT_DB)


def _unavailable(reason):
    return {"status": "unavailable", "reason": reason, "summaries": []}


def _shorten(value):
    value = " ".join(str(value or "").split())
    if len(value) <= MAX_FIELD_CHARS:
        return value
    return value[: MAX_FIELD_CHARS - 1].rstrip() + "…"


def _files(value):
    try:
        data = json.loads(value or "[]")
    except (TypeError, ValueError):
        return []
    return [str(item) for item in data] if isinstance(data, list) else []


def _fetch(path, root_text, prefix, name):
    uri = "file:" + quote(str(path)) + "?mode=ro"
    conn = sqlite3.connect(uri, uri=True, timeout=2)
    conn.row_factory = sqlite3.Row
    try:
        params = {"root": root_text, "n": len(prefix), "prefix": prefix, "name": name}
        return conn.execute(QUERY, params).fetchall()
    finally:
        conn.close()


def _choose(rows, root_text, prefix, name):
    """Renvoie (lignes retenues, type de correspondance)."""
    by_cwd, foreign, same_name = [], [], []
    for row in rows:
        cwd = row["cwd"]
        if cwd is not None and (cwd == root_text or cwd.startswith(prefix)):
            by_cwd.append(row)
        elif row["project"] == name and (cwd is None or not cwd.startswith("/")):
            foreign.append(row)
        elif row["project"] == name:
            same_name.append(row)
    if by_cwd or foreign:
        if by_cwd and foreign:
            return by_cwd + foreign, "cwd+name"
        return (by_cwd, "cwd") if by_cwd else (foreign, "name")
    return (same_name, "name") if same_name else ([], "cwd")


def read_claude_mem(root, since, until, last_journal_date, path=None):
    path = Path(path) if path else db_path()
    if not path.exists():
        return _unavailable(f"base introuvable: {path}")
    root_text = str(root)
    prefix = root_text.rstrip("/") + "/"
    name = Path(root_text).name
    try:
        rows = _fetch(path, root_text, prefix, name)
    except sqlite3.Error as exc:
        return _unavailable(f"base illisible ou schéma inattendu: {exc}")
    chosen, match = _choose(rows, root_text, prefix, name)
    summaries = []
    for row in sorted(chosen, key=lambda r: r["created_at"] or ""):
        found = DAY_RE.match(row["created_at"] or "")
        if not found:
            continue
        day = found.group(0)
        if (since and day < since) or (until and day > until):
            continue
        summaries.append(
            {
                "date": day,
                "request": _shorten(row["request"]),
                "investigated": _shorten(row["investigated"]),
                "learned": _shorten(row["learned"]),
                "completed": _shorten(row["completed"]),
                "next_steps": _shorten(row["next_steps"]),
                "files_edited": _files(row["files_edited"]),
                "unvalidated": last_journal_date is None or day > last_journal_date,
            }
        )
    return {"status": "ok", "match": match, "summaries": summaries}


def read_graphify(root):
    path = Path(root) / "graphify-out" / "GRAPH_REPORT.md"
    try:
        text = path.read_text(encoding="utf-8")
    except (OSError, UnicodeDecodeError):
        return {"status": "absent"}
    excerpt = text[:MAX_GRAPHIFY_CHARS]
    if len(text) > MAX_GRAPHIFY_CHARS and "\n" in excerpt:
        excerpt = excerpt.rsplit("\n", 1)[0]
    return {"status": "ok", "excerpt": excerpt.strip()}
```

```python
import re
from pathlib import Path

from . import registers, reports, sources
from .errors import CarnetError

DATE_RE = re.compile(r"^\d{4}-\d{2}-\d{2}$")


def _check_date(label, value):
    if value is not None and not DATE_RE.match(value):
        raise CarnetError("date_invalide", f"--{label}: {value}")


def build(root, since=None, until=None, gabarit=None, today=None, db_path=None):
    root = Path(root)
    until = until or today or registers.today_iso()
    journal = registers.read_journal(root)
    last_journal_date = max((entry["date"] for entry in journal), default=None)
    previous = reports.last_report(root, gabarit) if gabarit else None
    if since == "journal":
        since = last_journal_date
    elif since == "rapport":
        if not gabarit:
            raise CarnetError("gabarit_requis", "--since rapport demande --gabarit")
        since = previous["date"] if previous else None
    _check_date("since", since)
    _check_date("until", until)

    def in_period(day):
        return bool(day) and (since is None or day >= since) and (until is None or day <= until)

    decisions = registers.read_entries(root, "decisions")
    learnings = registers.read_entries(root, "learnings")
    blockers = registers.read_entries(root, "blockers")
    return {
        "project": {
            "root": str(root),
            "name": root.name,
            "initialized": registers.memory_dir(root).is_dir(),
        },
        "since": since,
        "until": until,
        "registers": {
            "decisions": [e for e in decisions if in_period(e["date"])],
            "learnings": [e for e in learnings if in_period(e["date"])],
            "blockers": {
                "opened": [e for e in blockers if in_period(e["date"])],
                "open": [e for e in blockers if e["statut"] == "ouvert"],
                "resolved": [
                    e
                    for e in blockers
                    if e["statut"] == "résolu" and in_period(e.get("resolu_le") or e["date"])
                ],
            },
            "journal": [e for e in journal if in_period(e["date"])],
            "last_journal_date": last_journal_date,
            "last_dates": registers.last_dates(root),
        },
        "previous_report": previous,
        "claude_mem": sources.read_claude_mem(root, since, until, last_journal_date, path=db_path),
        "graphify": sources.read_graphify(root),
    }
```

````markdown
  - `--depuis <date>`: `--since <date>`.
  - `--tout`: pas de `--since`.
  - par défaut: `--since rapport`, c'est-à-dire depuis le dernier rapport du même gabarit.

## 2. Rassembler la matière

```bash
python3 "${CLAUDE_SKILL_DIR}/../../bin/carnet.py" context --since rapport --gabarit entreprise
```

Remplace `entreprise` par le gabarit choisi, et ajuste `--since` selon la période. Avec `--tout`, retire `--since` et garde `--gabarit`.

Si `previous_report` n'est pas `null`, lis le fichier indiqué dans `path` pour ne pas répéter ce qu'il couvrait déjà.

## 3. Vérifier qu'il y a de quoi écrire

- Si `project.initialized` vaut `false`, ou si les registres sont vides sur la période mais que `claude_mem.summaries` contient des résumés: propose de lancer `/carnet:wrapup` d'abord, c'est ce qui rend le rapport fiable. Si l'utilisateur préfère continuer, fais un brouillon et mets en première ligne `> Brouillon non validé: basé sur claude-mem sans rituel de fermeture`. Dis-lui de retirer cette ligne avant d'envoyer.
- Si rien n'existe sur la période (ni registres, ni résumés), dis-le et arrête-toi. N'écris pas de rapport vide.
- Si `claude_mem.status` vaut `unavailable`, dis-le en une ligne (avec `reason`) et continue avec les registres.

## 4. Rédiger

Lis le gabarit avec l'outil Read:
- `${CLAUDE_SKILL_DIR}/../../templates/perso.md`
- `${CLAUDE_SKILL_DIR}/../../templates/entreprise.md`

Suis-le à la lettre: squelette, d'où vient chaque section, règles de fond, règles de style. Trois règles passent avant tout:
1. Chaque affirmation vient d'une entrée de registre ou d'un résumé claude-mem. N'invente rien, ni fait, ni date, ni chiffre.
2. Les résumés claude-mem sont souvent en anglais. Réécris-les en français.
3. Un résumé `unvalidated` n'a pas eu son rituel: dis-le à l'utilisateur.

## 5. Contrôler le style

Écris le brouillon dans un fichier temporaire, puis lance le contrôle dans le même appel Bash:

```bash
draft="$(mktemp)"
cat > "$draft" <<'MD'
(le rapport)
MD
python3 "${CLAUDE_SKILL_DIR}/../../bin/carnet.py" style-check entreprise --from "$draft"
echo "brouillon: $draft"
```

Remplace `entreprise` par le gabarit choisi. Corrige chaque avertissement de `warnings` (tiret cadratin, expression creuse, ID interne, trop de mots), puis relance jusqu'à ce qu'il n'en reste plus, ou jusqu'à ce que les restes soient voulus. Les avertissements ne bloquent jamais: l'utilisateur a le dernier mot.

## 6. Montrer, retoucher, valider

Affiche le rapport. L'utilisateur demande des retouches, tu les fais et tu relances le contrôle de style. Quand il valide:

```bash
python3 "${CLAUDE_SKILL_DIR}/../../bin/carnet.py" save-report entreprise --from /tmp/chemin-du-brouillon --du 2026-10-01 --au 2026-10-14
```

- `--from`: le chemin du brouillon affiché à l'étape 5.
- `--du`: la valeur `since` de la sortie de `context`, ou le mot `début` quand elle vaut `null`.
- `--au`: la valeur `until` de la sortie de `context`.

Donne à l'utilisateur le `path` du rapport enregistré. S'il reste des `warnings`, rappelle-les.
````
